# ⚡ bun-p2p (`vtx`)

> Zero-relay, end-to-end encrypted real-time terminal pair-programming and memory-to-memory file streaming powered by **Bun**, **TypeScript**, and **WebRTC DataChannels**.

---

## 🌟 Key Highlights

- **✨ Interactive Auto & Wizard Mode:** Run `bun-p2p` with zero arguments or `bun-p2p auto` to launch the interactive arrow-key wizard.
- **🚀 Embedded Auto-Signaling:** Host sessions spawn an in-process signaling broker in milliseconds without needing to start external servers.
- **🔗 Smart Connection Strings:** Connect directly via room codes or LAN IP shorthands (e.g. `VTX-482@192.168.1.35`).
- **🔒 End-to-End Encrypted (E2EE):** WebRTC DataChannels secured with DTLS-SRTP & SCTP, plus visual **SAS (Short Authentication String)** identity matching.
- **🖥️ Native PTY Mirroring:** Direct pseudo-terminal allocation (`openpty` / `ioctl` via `bun:ffi`) with automatic window resize synchronization (`SIGWINCH`), raw ANSI streaming, and Collab (`--mode=collab`) vs View (`--mode=view`) modes.
- **📦 Direct Memory-to-Memory File Streaming:** Stream single files or recursive directory trees in 64KB chunks with backpressure management, real-time speed/progress indicators, and end-to-end SHA-256 checksum verification.
- **📶 Air-Gapped / Offline Pairing:** Single-line compressed Base64 SDP exchange or terminal QR codes (`bun-p2p host --manual` / `bun-p2p pair`).

## 📦 Installation & Aliases

Ensure you have [Bun](https://bun.sh) (v1.1+) installed:

```bash
# Clone the repository
git clone https://github.com/vortex-labs/bun-p2p.git
cd bun-p2p

# Install dependencies
bun install

# Link globally (provides 'bun-p2p', 'vtx', and 'vortex-auto' commands)
bun link
```

## 🚀 Quickstart & Usage

### 1. Interactive Wizard (Default)
Simply run the CLI without subcommands:

```bash
bun-p2p
# or
vtx
```

```
? What would you like to do?
  (Use ↑/↓ arrows or number keys, Enter to confirm)
➜ [1] 🚀 Host Terminal Session (Share pseudo-terminal with embedded auto-signaling)
  [2] 🔗 Join Terminal Session (Connect to remote terminal via room code or IP)
  [3] 📦 Send File / Folder (Direct P2P memory-to-memory chunked streaming)
  [4] 📥 Receive File / Folder (Wait for incoming P2P binary stream)
  [5] ⚡ Start Dedicated Signaling Server (Run standalone WebSocket coordinator)
```

---

### 2. Terminal Pair Programming

#### Host a Terminal Session (Auto-Signaling Embedded)
```bash
# Automatically creates room 'VTX-xxx' and in-process signaling server on port 8765
bun-p2p host

# Host with custom room and read-only spectator mode
bun-p2p host --room dev-room --mode view
```

The host displays a ready-to-copy join command for peers on the same LAN:
```
✔ Connected to signaling broker. Waiting for peer...
  LAN Join String: VTX-482@192.168.1.35

  Peer can join via:
    bun-p2p join VTX-482 --relay ws://192.168.1.35:8765
    (or shorthand: bun-p2p join VTX-482@192.168.1.35)
```

#### Join a Shared Terminal
```bash
# Join using the shorthand connection string
bun-p2p join VTX-482@192.168.1.35

# Or paste the full join command generated by the host
bun-p2p join VTX-482 --relay ws://192.168.1.35:8765
```

#### Hotkeys during Terminal Sessions
- `Ctrl+]` or `Ctrl+Q`: Open session overlay menu (toggle Collab/View mode, disconnect).
- `Ctrl+C`: In View mode, cleanly exits. In Collab mode, forwarded to remote shell.

---

### 3. Direct Memory-to-Memory File Streaming

#### Send Files or Directories
```bash
# Stream a single file
bun-p2p send ./archive.tar.gz

# Stream an entire folder structure recursively
bun-p2p send ./project-folder
```

#### Receive Files
```bash
# Wait for incoming files in the specified room
bun-p2p receive ./downloads --room VTX-482@192.168.1.35
```

---

### 4. Air-Gapped / Offline Pairing (100% Offline / No Signaling)

For air-gapped networks, direct peer-to-peer LAN connections, or high-security environments:

```bash
# Interactive wizard
bun-p2p pair

# Or manual host / join flags:
bun-p2p host --manual
bun-p2p join --manual
```
1. Host generates a compressed `BUNP2P:<base64>` Offer token and displays an optional QR code.
2. Peer scans/pastes the Offer token and generates an Answer token.
3. Host pastes the Answer token — connection establishes directly over WebRTC DataChannels!

---

### 5. Dedicated Standalone Signaling Server

For teams hosting a central WebSocket relay on a server:

```bash
bun-p2p signal-server --port 8765 --host 0.0.0.0
```
